# Smart Offline Study

تطبيق أندرويد متكامل يعمل دون إنترنت لتصنيف النصوص والأسئلة الدراسية، تلخيصها، توليد بطاقات مراجعة واختبارات سريعة، واسترجاع الإجابات الموثقة من ملفات PDF وTXT المستوردة محلياً.

## المزايا والوظائف
- **تصنيف هجين خفيف:** مصنّف Naive Bayes نصي مدمج مع أنماط وقواعد لغوية وهيكلية لتصنيف الفقرات إلى: **تعريف**، **تعليل**، **مسألة**، **تاريخ**.
- **استخراج الكلمات المفتاحية والتلخيص:** استخراج أبرز المصطلحات وتلخيص الفقرات عبر TF-IDF وترتيب الجمل.
- **بطاقات مراجعة واختبار سريع:** توليد سؤال/جواب تلقائي واختبار اختيار من متعدد بمشتتات مستخرجة من النص والمحفوظات.
- **استيراد PDF وTXT والبحث في الكتب (`TF-IDF + Cosine Similarity`):** استرجاع أقرب فقرة مع اسم الملف ورقم الصفحة دون اختلاق إجابات عند ضعف التطابق.
- **تخزين محلي وتصدير:** قاعدة بيانات `SQLite` مع فلترة حسب الفئة، وتصدير `JSON` عبر `FileProvider`، واستقبال النصوص المشتركة (`ACTION_SEND`) والملفات (`ACTION_VIEW`).
